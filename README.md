# 🎬 Movies Catalog Project (MERN Stack)

## 📌 Overview
This is a full-stack Movies Catalog web application built using the MERN stack (MongoDB, Express.js, React.js, Node.js).  
The project allows users to view, search, add, update, and delete movie details using a responsive web interface and REST API backend.

---

## 🚀 Features
- 🎥 Display list of movies
- 🔍 Search movies by title
- ➕ Add new movies (Admin feature)
- 📝 Edit movie details
- ❌ Delete movies
- 🌐 REST API integration between frontend and backend
- 📱 Responsive UI design for all devices

---

### Frontend:
